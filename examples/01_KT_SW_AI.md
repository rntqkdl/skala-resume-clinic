# [KT] 2026년 대졸신입 채용 - NW 인프라 운용 / SW 개발 모범 사례

## 문항 1. 지원한 직무와 관련된 본인의 역량과 이를 쌓아온 경험을 본인이 맡았던 역할과 그 결과를 포함하여 구체적으로 기술해 주십시오. (최대 800자)

### [데이터로 장애를 먼저 찾고, 0.1초 만에 막아내는 인프라 엔지니어]
저는 대규모 데이터 속에서 장애 징후를 빠르게 찾아내고, 문제가 생기면 0.1초 만에 시스템을 자동 차단해 무중단 운영을 만드는 엔지니어입니다. 두 번의 프로젝트에서 데이터 분석과 파이프라인 구축을 주도하며 이 역할을 실전에서 증명했습니다.

첫째, 데이터 분석으로 이상 징후를 감지하고 0.1초 만에 시스템을 자동 차단했습니다.
네트워크에 연결된 인프라를 개발하며 정상 데이터(2,000L/h)와 고장 데이터(0~380L/h)의 시계열 분포를 분석했습니다. 이를 바탕으로 단순 통신 잡음과 실제 고장을 칼같이 가르는 장애 기준값(500L/h)을 도출했습니다. 그리고 비정상 신호 감지 즉시 0.1초 만에 시스템을 멈추고 장비를 보호하는 제어 루프를 구현해 캡스톤 디자인 경진대회 은상을 받았습니다.

둘째, 데이터 정제 파이프라인을 구축해 위협 탐지율을 대폭 끌어올렸습니다.
DACON 보안 경진대회 당시 원천 데이터 노이즈 탓에 기존 모델의 탐지 성능은 F1-Score 0.67에 그쳤습니다. 저는 통신망 관제는 데이터의 순도가 핵심이라 판단하여, 실시간 API 연동과 자동 정제 파이프라인을 직접 구축해 노이즈를 걷어냈습니다. 그 결과 탐지 성능을 F1-Score 0.95로 41.8%p 개선하며 우수상을 받았습니다.

데이터로 장애를 먼저 읽어내고 0.1초 만에 차단하는 실행력으로, 365일 24시간 멈추지 않는 KT 네트워크의 안정성을 책임지겠습니다.

## 문항 2. AI 기술을 활용하여 성과를 창출한 경험을 구체적으로 기술해 주십시오. (판단/조정, 역할, 기여도) (최대 600자)

### [소외된 1%의 데이터도 살려내 모델 성능을 극대화하는 AI 엔지니어]
저는 남들이 지나치는 희귀 데이터까지 끝까지 살려내 인공지능의 성능을 극대화하는 엔지니어입니다. 이 집요함으로 롱테일 불균형을 극복하고 전국 30개 팀 중 1위 대상(IITP 원장상)을 받았습니다.

지능정보 SW아카데미 프로젝트 당시 14,881장의 원천 데이터에서 13,000종 한자가 1:907로 치우쳐, 기존 모델은 희귀 한자를 42%나 오분류하며 겉돌았습니다.

저는 단 하나의 데이터도 버리지 않겠다는 각오로, 데이터 빈도수 제곱근의 역수를 손실함수에 직접 수학적으로 설계해 모델이 희귀 패턴을 더 깊이 학습하도록 이끌었습니다. 이어 Swin Transformer V2 백본과 헤드에 차등 학습률을 주는 2-Tier 최적화로 학습의 흔들림을 완벽히 잡았습니다.

그 결과 기본 교차 엔트로피 모델의 한계를 깨부수고 희귀 클래스 오분류를 대폭 낮추며 Top-1 정확도 96.63%, Top-5 99.38%로 전국 1위 대상을 견인했습니다.

미세한 이상 데이터도 놓치지 않는 집요함으로 KT AICT 네트워크의 품질 혁신을 이끌겠습니다.

## 문항 3. KT의 핵심가치인 'KT Professionalism'이 본인의 행동으로 드러난 경험을 구체적으로 기술해 주십시오. (최대 600자)

### [말보다 객관적인 데이터로 갈등을 풀고 결과를 내는 프로페셔널]
저는 팀의 기술적 갈등을 주관적 주장이 아닌 '객관적 데이터 검증'으로 해결하고, 규격을 표준화해 프로젝트를 완결 짓는 프로페셔널입니다. 4인 팀 프로젝트에서 2,000건의 A/B 벤치마크 테스트와 스키마 표준화를 주도해 전국 1위 대상을 달성하며 이를 입증했습니다.

프로젝트 당시 고해상도 처리를 위해 거대한 단일 모델을 고집하는 팀원과 경량 앙상블을 원하는 팀원의 대립으로 개발이 중단될 위기였습니다. 저는 소모적 논쟁 대신 2,000건의 통제 검증셋을 구성해 누구도 반박할 수 없는 정량적 A/B 테스트 환경을 직접 구축했습니다.

테스트 결과 경량 앙상블이 메모리는 45% 덜 쓰면서 응답 속도는 0.3초 빠르고, F1-Score조차 3.2%p 더 우수하다는 명쾌한 숫자를 제시해 팀원 전원의 합의를 이끌어냈습니다. 나아가 파트 간 규격을 JSONL 스키마로 표준화해 병목을 없애며 30개 팀 중 1위 대상을 달성했습니다.

타협 없는 전문성과 숫자로 입증하는 신뢰로 KT 고객에게 결점 없는 최상의 네트워크를 선물하겠습니다.
