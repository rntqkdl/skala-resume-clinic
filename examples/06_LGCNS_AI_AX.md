## 문항 1: [Why LG CNS] LG CNS에 지원한 동기와 입사 이후 꿈꾸는 것은 무엇인가요? (최대 500자)

### [4초 지연의 데모를 넘어 24시간 무중단으로 동작하는 엔터프라이즈 AI를 향해]
연구실 데모의 높은 정확도에 안주하지 않고, 24시간 무중단으로 동작하는 프로덕션 AI 서비스를 구현하고자 LG CNS에 지원했습니다. 13,974종 고문서 복원 프로젝트에서 1위 대상을 달성했지만, 초기 서빙 시 4초 이상의 긴 추론 지연과 단일 장애점 위험을 직접 겪었습니다. 모델의 수학적 성능 못지않게 중요한 것은 현업 사용자가 지체 없이 신뢰할 수 있는 무중단 서빙 인프라임을 체감했습니다. 이에 Docker 멀티스테이지와 Kubernetes 롤링 업데이트 기반 무중단 환경을 직접 구축하고 RAG 파이프라인을 연동해 검색 시간을 60분에서 5분으로 91.7% 단축했습니다.
입사 후 제조, 금융 현장의 복잡한 비정형 데이터를 DAP GenAI로 연결하고, 지연과 데이터 유실 없는 고가용성 엔터프라이즈 AX 파이프라인을 완성하겠습니다.

## 문항 2: [My Competency] 지원 분야와 관련된 구체적인 지식이나 경험을 기술해 주십시오. (최대 1,000자)

#AI #DeepLearning #Vision #NLP #Cloud
### [데이터 정제부터 K8s 무중단 서빙까지: 전주기를 직접 구축한 엔드투엔드 역량]
데이터 품질 정제부터 딥러닝 경량화, 백엔드 연동, Kubernetes 무중단 서빙에 이르는 전주기 AI 파이프라인을 직접 구축하며 엔터프라이즈 실서비스 역량을 검증받았습니다.

첫째, 13,974종 고문서 판독에서 베이스라인 58.4% 대비 38.2%p 향상된 Top-1 96.63%를 달성해 30개 팀 중 1위 대상(IITP 원장상)과 KIIT 학술지 논문 게재를 이뤄냈습니다. 상위 20자가 30%를 독점하는 1:907 롱테일 불균형으로 인한 소수 클래스 그래디언트 소실을 규명하고, 빈도수 제곱근 역수 손실함수를 직접 설계했습니다. 이어 Swin Transformer V2 백본(3e-5)과 헤드(3e-4)의 2-Tier 차등 학습률을 적용해 Top-5 99.38%를 확보하며 수렴을 안정화했습니다.

둘째, DACON 금융 보안 경진대회에서 신종 변형 피싱 탐지율 91.5%와 F1-Score 0.95를 기록하며 우수상을 수상했습니다. 개념 드리프트로 기존 F1-Score가 0.67에 정체된 한계를 극복하고자 GPT-4o(공격 생성)와 KLUE-RoBERTa(방어 탐지)가 경쟁하는 적대적 파이프라인을 구축하고 뉴스 비정형 텍스트 4단계 자동 정제 체계를 구현해 변형 공격 방어력을 극대화했습니다.

셋째, SpringBoot 3 백엔드와 Vector DB 기반 RAG 시스템을 구축해 사내 문서 검색 시간을 60분에서 5분으로 91.7% 단축했습니다. Docker 멀티스테이지 빌드로 컨테이너 용량을 기존 대비 70% 절감하고 Kubernetes 무중단 롤링 업데이트 환경을 구현했습니다. 이처럼 모델과 인프라를 아우르는 전주기 엔지니어링 역량으로 LG CNS의 성공적인 AX 전환을 뒷받침하겠습니다.

### [거대 모델의 환상을 깬 2,000건 부하 테스트: 실측 데이터로 이끈 앙상블 합의]
거대 단일 모델만을 고집하던 주관적 주장을 2,000건의 API 부하 테스트 실측 데이터로 전환해 팀 합의를 이끌고, 30개 팀 중 최종 1위 대상을 견인했습니다.
13,974종 고문서 복원 프로젝트 당시, 판독 정확도를 위해 거대 모델을 고집하는 팀원과, 실제 프로덕션 서빙 지연 및 메모리 부하를 고려해 경량 멀티모달 앙상블을 제안한 저 사이에 치열한 의견 충돌이 발생했습니다.
주관적 논쟁을 멈추고자 실제 API 부하 환경에서 2,000건의 검증셋으로 정량적 A/B 벤치마크 테스트를 직접 주도했습니다. 실측 결과 경량 앙상블이 메모리를 45% 절감하고 응답 속도를 0.3초 단축하며 F1-Score는 3.2%p 우수함을 증명해 전원 합의를 도출했습니다. 이어 4개 파트 간 데이터 규격을 JSONL 스키마로 표준화해 파이프라인 병목을 제거했습니다.
