## 문항 1: [Why LG CNS] LG CNS에 지원한 동기와 입사 이후 꿈꾸는 것은 무엇인가요? (최대 500자)

### [DAP GenAI 플랫폼의 데이터 병목을 해소하는 실전형 AX 엔지니어]
저는 AI 모델링에 그치지 않고 엔터프라이즈 환경의 I/O 병목을 해결해 무중단 프로덕션 서비스를 구축하는 데 차별화된 강점이 있습니다. 13,974종 고문서 복원 프로젝트에서 최종 1위 대상을 수상하며 초기 4초 이상의 긴 추론 지연과 서버 불안정성을 직접 겪었습니다. 실무 서빙 인프라의 중요성을 체감하고, Docker 멀티스테이지와 Kubernetes 무중단 배포 체계 및 RAG 파이프라인을 구축해 사내 검색 시간을 60분에서 5분으로 91.7% 단축했습니다.
LG CNS는 DAP GenAI 플랫폼으로 제조, 금융의 엔터프라이즈 AX 전환을 선도하고 있습니다. 입사 후 현장의 복잡한 비정형 데이터를 표준화하고, 0.1초대 저지연과 무결점 정제 파이프라인을 결합해 고객사가 신뢰하는 고가용성 생성형 AI 엔터프라이즈 서비스를 구축하겠습니다.

## 문항 2: [My Competency] 지원 분야와 관련된 구체적인 지식이나 경험을 기술해 주십시오. (최대 1,000자)

#AI #DeepLearning #Vision #NLP #Cloud
### [13,974종 불균형 손실함수 설계와 적대적 파이프라인 기반 엔터프라이즈 AX 구축]
데이터의 구조적 병목을 수학적 모델링으로 돌파하고, 이를 클라우드 인프라 기반의 실서비스로 완성하는 것이 저의 핵심 직무 전문성입니다.

첫째, [RCA 및 손실함수 설계]: 13,974종 고문서 판독 프로젝트 당시 1:907 롱테일 불균형으로 초기 모델 정확도가 58.4%에 정체하는 한계를 분석했습니다. 다수 클래스 그래디언트가 희귀 클래스를 압도하는 현상을 규명하고, 빈도수 제곱근 역수 가중치를 손실함수에 직접 설계하여 희귀 클래스 학습 집중을 유도했습니다. 이어 Swin Transformer V2 백본과 헤드의 2-Tier 차등 학습률을 적용했습니다. 그 결과 기존 베이스라인 58.4% 대비 38.2%p 향상된 Top-1 96.63%를 달성해 30개 팀 중 1위 대상(IITP 원장상) 수상과 KIIT 학술지 논문 게재로 입증했습니다.

둘째, [적대적 공생 파이프라인]: DACON 보안 경진대회에서 신종 변형 피싱의 개념 드리프트로 기존 모델 F1-Score가 0.67에 머무르는 한계를 포착했습니다. GPT-4o와 KLUE-RoBERTa가 경쟁하는 적대적 파이프라인을 구축하고 뉴스 비정형 텍스트 4단계 자동 정제를 구현했습니다. 이를 바탕으로 변형 탐지율을 기존 42.0%에서 91.5%로 대폭 끌어올리고 F1-Score 0.95를 달성하며 우수상을 수상했습니다.

셋째, [엔터프라이즈 RAG 인프라]: SpringBoot 3 백엔드에 LangChain과 Vector DB를 결합한 RAG 시스템을 구축해 사내 문서 검색 시간을 60분에서 5분으로 91.7% 단축했습니다. Docker 멀티스테이지 빌드로 컨테이너 용량을 기존 대비 70% 절감하고 Kubernetes 무중단 롤링 업데이트 체계를 구현했습니다.

## 문항 3: [Collaboration] 공동의 목표를 달성하는 과정에서 본인과 다른 의견을 가진 사람과 협업했던 경험을 기술해 주십시오. (최대 500자)

### [2,000건 A/B 벤치마크 테스트와 표준화로 기술적 대립을 극복하고 대상을 이끌다]
저는 기술적 의견 대립이 발생했을 때 주관적 주장 대신 객관적인 데이터 벤치마크와 표준화로 합의점을 도출하는 엔지니어입니다.
13,974종 고문서 복원 프로젝트 당시, 정확도를 위해 거대 단일 모델을 고집하는 팀원과, 서빙 지연과 메모리 부하를 고려해 경량 멀티모달 앙상블을 구축해야 한다는 저의 의견이 맞섰습니다.
소모적 논쟁을 멈추고자 실제 API 환경에서 2,000건의 통제 검증셋으로 정량적 A/B 벤치마크 테스트를 직접 주도했습니다. 실측 결과 경량 앙상블이 메모리를 45% 절감하고 응답 속도를 0.3초 단축하며 F1-Score는 3.2%p 우수하다는 객관적 지표를 증명해 전원 합의를 이끌어냈습니다.
이어 4파트 간 입출력 규격을 JSONL 스키마로 표준화해 병목을 제거하고 30개 팀 중 1위 대상을 달성했습니다.

### [임시변통을 거부하고 메커니즘 추적으로 근본 결함을 제거하는 원칙]
저는 시스템의 결함과 지연을 유발하는 근본 원인을 끝까지 추적해 재현 가능한 방어벽을 구축하는 엔지니어링 원칙을 지키고 있습니다.
IT융합기전공학을 전공하며 사소한 센서 노이즈 하나가 시스템 전체를 멈출 수 있음을 체감했습니다. 이 경험은 문제 발생 시 임시방편 패치에 의존하지 않고, 로그 프로파일러 기반으로 가장 취약한 병목 지점을 규명해 해결하는 작업 습관으로 이어졌습니다.
이러한 기준은 AI 모델 개발 시 1:907 불균형의 수학적 원인을 분석해 손실함수를 직접 설계하게 만든 원동력으로 작용했고, 클라우드 파이프라인 구축 시에도 배포 단계 병목을 사전 차단해 무중단 롤링 업데이트 체계를 완성하는 기반을 구축했습니다.
화려한 데모보다 보이지 않는 결함을 추적해 무중단 고가용성 시스템을 완성하는 것이 변함없는 직무 기준입니다.
