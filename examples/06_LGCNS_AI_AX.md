# [LG CNS] 2026년 하반기 신입사원 채용 - AI (AX)

## 문항 1: [Why LG CNS] LG CNS에 지원한 동기와 입사 이후 꿈꾸는 것은 무엇인가요? (최대 500자)

### [데모를 넘어 엔터프라이즈 무중단 운영을 실현하는 실전형 AX 엔지니어]
연구실 데모 수준의 정확도에 안주하지 않고, 현업 비즈니스 환경에서 24시간 무중단으로 구동되는 AI 서비스를 구현하고자 LG CNS에 지원했습니다. 13,974종 고문서 복원 프로젝트에서 1위 대상을 달성하는 과정에서, 가상 환경과 실제 서비스 환경 사이의 지연과 인프라 병목을 직접 체감했습니다. 모델링에 머무르지 않고 Spring Boot 마이크로서비스를 Docker 멀티스테이지 빌드로 경량화하고, Kubernetes 클러스터 배포 및 Vector DB 기반 RAG 검색 파이프라인을 구축하며 실서비스 가용성 확보 역량을 다졌습니다.
LG CNS는 DAP GenAI 플랫폼을 바탕으로 제조, 금융 현장의 AX 혁신을 주도하고 있습니다. 입사 후 현장의 복잡한 비정형 데이터를 표준화하고 지연 없는 고가용성 엔터프라이즈 AI 파이프라인을 완성하겠습니다.

## 문항 2: [My Competency] 지원 분야와 관련된 구체적인 지식이나 경험을 기술해 주십시오. (최대 1,000자)

#AI #DeepLearning #Vision #NLP #Cloud
### [13,974종 불균형 해소와 K8s 무중단 서빙: 전주기를 직접 구축한 엔드투엔드 역량]
데이터 품질 정제부터 딥러닝 모델링, 백엔드 연동, Kubernetes 무중단 서빙에 이르는 전주기 AI 파이프라인을 직접 구축하며 엔터프라이즈 실서비스 역량을 입증했습니다.

첫째, 13,974종 고문서 판독에서 베이스라인 58.4% 대비 38.2%p 향상된 Top-1 96.63%, Top-5 99.38%를 달성해 30개 팀 중 1위 대상(IITP 원장상)과 KIIT 논문 게재를 이뤄냈습니다. 상위 20자가 30%를 독점하는 1:907 롱테일 불균형을 극복하기 위해 빈도수 제곱근 역수 손실함수를 직접 설계했습니다. Swin Transformer V2 백본(3e-5)과 헤드(3e-4)의 2-Tier 차등 학습률을 적용하고 7대 품질 지표 IQR 분석으로 13,966개 원천 탁본에서 9,970개 고품질 데이터셋을 정제했습니다.

둘째, DACON 금융 보안 경진대회에서 신종 변형 피싱 탐지율 91.5%와 F1-Score 0.95를 기록하며 우수상을 수상했습니다. 개념 드리프트 극복을 위해 Google News RSS 및 Naver API 기반 비정형 텍스트 4단계 정제 파이프라인을 구축하고, GPT-4o(공격 생성)와 KLUE-RoBERTa(방어 탐지)가 경쟁하는 적대적 공생 구조를 구현해 기존 F1-Score 0.67을 0.95로 대폭 끌어올렸습니다.

셋째, Spring Boot와 Vector DB 기반 RAG 시스템을 구축하고, Docker 멀티스테이지 빌드와 Kubernetes 클러스터 롤링 업데이트 배포 체계를 구현해 시스템 가용성을 보장했습니다. 모델 설계부터 클라우드 배포까지 병목을 제거하는 전주기 역량으로 LG CNS의 성공적인 AX 전환을 뒷받침하겠습니다.

## 문항 3: [Collaboration] 공동의 목표를 달성하는 과정에서 본인과 다른 의견을 가진 사람과 협업했던 경험을 기술해 주십시오. (최대 500자)

### [정기 정량 리뷰 도입과 역할 문서화로 작업 중복을 제로화한 PM 협업]
역할 모호로 인한 실패를 시스템으로 극복하여 5개월간 작업 중복 0건과 93건의 무충돌 커밋 관리로 30개 팀 중 최종 1위 대상을 견인했습니다.
이전 프로젝트에서 역할 경계가 흐려 동일 파라미터 튜닝을 중복 수행하며 일주일간의 실험 시간과 6시간의 학습 시간을 낭비한 실패를 겪었습니다. 이 경험에서 단순한 친분보다 명확한 규칙이 성과를 보장한다는 원칙을 체득했습니다.
이후 EpiText 프로젝트 PM으로서 첫 주에 Vision, NLP, Backend, Frontend 영역별 담당 업무를 명확히 문서화했습니다. 이어 매주 [실험 내용 -> 정확도 및 Loss 수치 결과 -> 차주 계획]을 정량 공유하는 정기 리뷰 프로세스를 정착시켰습니다.
결과적으로 백엔드 41건, 프론트엔드 52건의 커밋을 단 한 번의 충돌 없이 조율하며 IITP 원장상 대상을 달성했습니다.

## 문항 4: [Work Values] 자신을 가장 잘 표현할 수 있는 직무 가치관이나 일하는 기준을 기술해 주십시오. (최대 500자)

### [가상과 현업의 괴리를 직시하고 보이지 않는 결함을 정량 제어하는 원칙]
가상 환경의 안일함을 경계하고 시스템의 보이지 않는 결함과 노이즈를 정량 데이터로 끝까지 통제하는 것이 저의 일관된 엔지니어링 기준입니다.
IT융합기전공학과 IoT 센서 제어 프로젝트를 수행하며 사소한 물리 신호 노이즈 하나가 전체 인프라를 멈출 수 있음을 체감했습니다. 문제 발생 시 임시방편 패치에 의존하지 않고 정상(2,000L/h)과 사고(0~380L/h) 실험 데이터를 반복 측정해 최적 임계값 500L/h를 도출하고 0.1초 즉시 제어를 구현했습니다.
이 기준은 AI 개발 시에도 가상 데이터에 안주하지 않고 7대 지표 IQR 이상치 정제와 1:907 불균형 손실함수를 직접 설계하게 만든 원동력이 되었습니다.
화려한 데모보다 보이지 않는 결함을 추적해 무중단 고가용성 시스템을 완성하는 엔지니어로서 LG CNS의 프로덕션 신뢰성을 책임지겠습니다.
