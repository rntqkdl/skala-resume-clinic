# 어떤 기업이든 5분 만에 즉시 핏(Fit)하게 작성하는 공채 자소서 치트시트

본 문서는 안성민 지원자의 마스터 경험 자산(EpiText 대상, DACON 우수상, Safe Drain Lock 은상)을 **어떤 기업, 어떤 직무의 문항이든 100% 핏(Fit)하게 매핑하여 즉시 작성**하기 위한 기업군별 고속 브릿징 가이드입니다.

## 2. Action-First 두괄식 공식 (내가 뭘 하는 사람인가)

질문에 대한 답이자 첫 문장은 미사여구를 배제하고 아래 공식으로 1초 만에 선언합니다.

> **공식**:  
> "저는 [기업의 핵심 과제]에서 [무슨 데이터를 분석해] [어떤 문제를 해결하고], [어떤 결과]를 만드는 엔지니어입니다."

### [실전 예시 1: KT / NW 인프라 운용]
> "저는 대규모 데이터 속에서 장애 징후를 빠르게 찾아내고, 문제가 생기면 0.1초 만에 시스템을 자동 차단해 무중단 운영을 만드는 엔지니어입니다."

### [실전 예시 2: 우리은행 / IT, 디지털]
> "저는 금융 거래의 안전을 위협하는 비정형 이상 데이터를 실시간으로 정제하고 걸러내어, 단 1건의 오탐도 없는 무결점 금융 시스템을 만드는 데이터 엔지니어입니다."

### [실전 예시 3: 네이버, 카카오 / AI, SW 엔지니어]
> "저는 남들이 포기하는 1%의 희귀 데이터까지 수학적으로 살려내 모델의 오분류율을 극복하고 실서비스 성능을 극대화하는 AI 엔지니어입니다."

### [실전 예시 4: LG CNS / DX 엔지니어]
> "저는 산업 현장의 수많은 센서 단말에서 쏟아지는 시계열 신호의 이상치를 분석해, 0.1초 만에 공정 장애를 방어하고 파이프라인을 자동화하는 DX 엔지니어입니다."

## 3. 군더더기 없는 초단문화 본문 전개 (Crisp STAR)

* **[소제목]**: [문제해결 액션 + 비교 가능한 정량 수치]
* **[도입 2줄]**: Action-First 두괄식 선언 + 프로젝트 및 수상 결과
* **[첫째 문단]**: [이상 감지 & 즉각 조치]
  - 센서/트래픽 정상치 vs 고장치 수치 제시 (Before)
  - 통계적 분석을 통해 도출한 최적 기준값 (Engineering Action)
  - 0.1초 자동 차단 또는 시스템 보호 조치 구현 (Impact)
  - 수상 결과 (Result)
* **[둘째 문단]**: [데이터 정제 & 성능 극대화]
  - 기존 모델의 한계 및 베이스라인 지표 명시 (F1-Score 0.67)
  - 실시간 API 연동 및 자동 정제 파이프라인 구축 (Engineering Action)
  - 개선된 지표 명시 (F1-Score 0.95로 41.8%p 개선)
  - 수상 결과 (Result)
* **[마무리 1줄]**: 기업의 최신 비전(예: KT의 AICT 무중단 통신, 은행의 무결점 디지털 금융)을 실현하겠다는 든든한 다짐
